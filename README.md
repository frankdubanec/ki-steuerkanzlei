# KI in der Steuerkanzlei

Deutschsprachige Informationswebseite mit Praxisbeispielen, Einstieg, rechtlichen Grundlagen und Quellen.

## Veröffentlichung

GitHub: Settings → Pages → Deploy from a branch → main → /(root) → Save.

Die HTML- und CSS-Dateien im Hauptverzeichnis bilden die vollständige statische Webseite.
